# HR Attrition Analytics Dashboard

## Project Overview

This project analyzes employee attrition patterns using Excel, Power BI, DAX and HR Analytics techniques.

The goal is to identify key attrition drivers, workforce demographics and employee retention trends.

## Project Highlights

- Analyzed 1,470 employee records
- Attrition Rate: 16.1%
- Built a 3-page interactive HR Analytics dashboard
- Identified major attrition drivers including overtime, low income and short tenure
- Performed workforce demographic analysis

## Tools Used

- Microsoft Excel
- Power BI
- DAX

## Data Preparation & Cleaning

- Validated missing values
- Checked duplicate records
- Created Age Groups
- Created Income Brackets
- Created Tenure Groups
- Built Attrition Flag metrics

## Dashboard Features

### HR Executive Dashboard
- Workforce KPIs

- Job Role Analysis
- Age Group Analysis

### Attrition Drivers Analysis

- Income Impact
- Tenure Analysis

### Workforce Demographics

## Key Insights

- Research & Development showed highest attrition
- Laboratory Technicians experienced highest employee turnover
- Employees with 0–2 years tenure had highest attrition
- Low income employees represented the largest attrition segment
- Overtime significantly impacted employee exits
